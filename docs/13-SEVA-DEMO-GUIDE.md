# 13 — Seva Demonstration Guide

## Five-minute script

1. Explain the offline failure problem.
2. Show the candidate interface and admin dashboard.
3. Simulate internet disconnection.
4. Show local storage and pending response status.
5. Simulate Node B failure and pause state.
6. Restore service and show synchronization.
7. Explain remaining limitations clearly.

## Sample judge questions

- What happens when internet fails?
- Why does Node B failure pause responses?
- Why is the witness node warning important?
